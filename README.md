# Active Time Tracker — downloads

Installer downloads and update checks for **Active Time Tracker (TimeCalc)**.
The application source is maintained in a private repository.

## Install
Download the latest `ActiveTimeTracker-Setup-x.y.z.exe` from
[Releases](../../releases/latest) and run it. No admin rights required.

Access is limited to approved users — if you see an "access not enabled"
message on first run, ask Samir Tak to add you.

## Updating
The app checks here automatically and shows an **i** badge in the overlay when
a new version is available. Click the badge to download it.
